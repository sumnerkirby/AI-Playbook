Your AI listcheck each use of each tool

A tool can be acceptable for one task and not for another, so each check covers one use: the tool, the plan it is on, and what it is used for. The result is a traffic light with the reasons for it, a to-do list, and a statement of what is allowed while the to-dos are open.
